# 时代小卖部

一个虚构小镇镇口的供销社门市，从 1984 年开到 2021 年。你始终站在柜台后面：客人走到柜台前，东西摆在台面上，你靠拿、放、推做决定。

## 在线试玩

- 柜台交互原型（当前方向，五位客人）：https://maxi-max-dev.github.io/shidai-xiaomaibu/
- 第一章完整版 v0.3（旧的对话式交互，五天、夜里、订货、糖票）：https://maxi-max-dev.github.io/shidai-xiaomaibu/chapter1.html

## 怎么玩（柜台原型）

- 客人放在柜台上的钱，拖进钱匣算收下；找零从钱匣拖到托盘。
- 货从货架抽屉拖到托盘；酱油用提子打进客人的瓶子里。
- 账本拖上托盘就是记账；东西推回托盘就是不要；拿放大镜可以和正品比一比。
- 按"推过去"，客人看托盘上的东西自己反应。拖不方便时，点一下也行。

## 题材边界

青石镇和所有人物都是虚构的。不出现真实人物、真实企业和政治事件，时代只通过物价、商品、日常生活和虚构的县报来写。
